# 3D_Movie_Theater_Graphics_Project
The Movie Theatre Visualization System is an interactive C++ and OpenGL application modeling cinema layouts and ticket booking. It features real-time 2D/3D seat rendering, dynamic availability color coding (Green/Yellow/Red), interactive selection, curtain/light animations, and event-driven GLUT input handling for graphical simulation.
